## 交互说明

- 底部前后页、页码缩略图跳页、键盘左右键、全屏。
- 阿语按钮默认关闭，点击显示教学翻译；刷新后恢复关闭，不保存选择。
- 音频点击播放，再次点击停止；翻页自动停止。
- S13、S18、S20 初始无完整答案，教师核对时才显示。
- S14 按施受反转、句块结构或动词形式选择帮助；撤帮助后不再显示完整答案。
- S17 使用可重播的三帧动态图景；S20 青蛙—昆虫图片与目标句、音频一致。
- S23 打开 `review.html`；复习页含听读资源、纯听辨、独立口语和无音频阅读四站，无语音输入，未接入既有数据存储。
- 听辨与阅读均记录首答成绩；首错后改对不回补，重练不覆盖首答成绩。
- S19 写句由学生本人输入；课件不冒充 WB 原题或真题。
- 事件暂存于浏览器 `window.lessonEvents`，未接入教学系统或 CRM。
